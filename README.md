# Hola, soy Sergio Rodríguez Pérez 👋

**Ingeniero en Telecomunicaciones y Electrónica** (CUJAE, 2026) · **Desarrollador Full Stack** en Antilla Capital

Trabajo entre el software y el hardware: desarrollo aplicaciones web full stack y diseño sistemas embebidos de bajo consumo con machine learning en el borde (Edge AI).

- 💼 Desarrollo aplicaciones de e-commerce y un ecosistema financiero digital con pasarela de pagos (React, Next.js, NestJS).
- 🔬 Investigué algoritmos de machine learning para microcontroladores MSP430 que detectan en tiempo real rupturas en redes de distribución de agua.
- 📄 Coautor de *"Wavelet-Based Machine Learning for Real-Time Burst Detection on Embedded Edge Devices"* (IHCONCS 2026, Zagreb).
- 🏆 Dos Premios Relevantes en eventos científicos nacionales por mi trabajo en sincronización de nodos por GPS con bajo consumo.
